## About the Project

This project is about analyzing restaurant data.

I used **Python** to understand and analyze the data and **Tableau** to create charts and dashboards.

The main goal of this project is to understand restaurant ratings, cuisines, cost, online delivery, table booking, and other restaurant details.

---

## Project Goals

- Understand the restaurant data.
- Clean and check the data using Python.
- Find useful information from the data.
- Check what factors are related to restaurant ratings.
- Create charts and dashboards using Tableau.
- Get useful business insights from the data.

---

## Dataset

The dataset contains **9,551 restaurants** and **19 columns**.

Some important columns are:

- Restaurant Name
- City
- Country Code
- Cuisines
- Average Cost for Two
- Table Booking
- Online Delivery
- Price Range
- Aggregate Rating
- Votes

## Main Questions

The project looks at questions such as:

- Which cuisines are common in different cities?
- Does the number of cuisines affect restaurant ratings?
- Does cost affect restaurant ratings?
- Does online delivery have any relation to ratings?
- Does table booking have any relation to ratings?
- What other factors are related to restaurant ratings?
